A deterministic Python program that writes one line — a dog's excuse after being caught eating the homework — to `entry.txt`.

## The entry

> I was only grading it. It failed. I ate the evidence so nobody would know.

74 characters (gate: 1–200). The dog plays teacher: it graded the homework, the homework failed, and the evidence had to go. No apology, no embarrassment — a dog that believes it did nothing wrong.

## Run

```sh
python3 main.py
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). No clock, no randomness, no network, no file reads — the output is the same every run.
